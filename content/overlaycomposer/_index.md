OverlayComposer brings your stream widgets into one place. Arrange alerts, chat, donation widgets, and custom sources in a visual editor — then let each OBS scene show its own layout.

## What it does

- **One Browser Source** — add a single overlay URL to OBS instead of managing many sources across scenes.
- **Scene-aware layouts** — create a layout for each OBS scene, with a default layout as a fallback.
- **Visual editor** — position, resize, rotate, crop, and organize layers on a canvas.
- **Extensible widgets** — use built-in sources, install plugins, or add your own HTML widgets.
