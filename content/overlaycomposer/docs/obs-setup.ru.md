# Подключение OverlayComposer к OBS

1. Запусти OverlayComposer.
2. В OBS добавь источник **Browser Source**.
3. Укажи URL: http://127.0.0.1:8000/overlay.
4. Установи ширину и высоту в соответствии с размером холста OBS, например 1920 × 1080.
5. Добавь тот же Browser Source в остальные сцены, где нужен оверлей.

OverlayComposer переключает отображаемый макет при смене активной сцены OBS. Если для сцены нет отдельного макета, будет показан макет по умолчанию.

По умолчанию сервер слушает 127.0.0.1:8000. Адрес и порт можно изменить в настройках. Не открывай сервер для локальной сети без понимания последствий: сейчас в приложении нет пользовательской авторизации.
