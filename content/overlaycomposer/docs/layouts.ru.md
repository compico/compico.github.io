# Макеты и редактор

Для каждой сцены OBS можно создать отдельный макет. Макет состоит из слоёв — виджетов и источников.

- Нажми на слой, чтобы выбрать его, и перетащи для перемещения.
- Потяни за угловые маркеры, чтобы изменить размер, или за маркер вращения, чтобы повернуть элемент.
- Используй панель свойств для настройки позиции, прозрачности и других параметров.
- Дважды нажми на название слоя, чтобы переименовать его.
- Используй команды Duplicate и Delete для управления слоями.

Удерживай **Alt** и перетаскивай маркер изменения размера, чтобы обрезать выбранный слой, не перемещая его содержимое.

Чтобы использовать виджет в другом макете, выбери **Copy to layout…** или нажми **Ctrl+C**, переключись на другой макет и нажми **Ctrl+V**. Копию можно оставить связанной с оригиналом, чтобы виджет сохранял состояние при переключении сцен, или сделать независимой.

**Ctrl+Z** отменяет действие, **Ctrl+Shift+Z** (или **Ctrl+Y**) повторяет его. Включи **Snap**, чтобы выравнивать слои по холсту и друг относительно друга.
