# Начало работы

1. Скачай последнюю версию со страницы [GitHub Releases](https://github.com/compico/overlaycomposer/releases).
2. Запусти OverlayComposer. Приложение поднимет локальный сервер и откроет редактор в браузере.
3. По умолчанию редактор доступен по адресу http://127.0.0.1:8000/editor.
4. Добавь источник, размести его в макете и сохрани изменения.

OverlayComposer работает локально на твоём компьютере. Адрес сервера по умолчанию — 127.0.0.1:8000.

Далее: [подключение к OBS](../obs-setup/) или [работа с макетами](../layouts/).
