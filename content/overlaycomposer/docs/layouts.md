# Layouts and editor

Each OBS scene can have its own layout. A layout contains layers representing widgets and sources.

- Click a layer to select it; drag to move it.
- Drag corner handles to resize and the rotation handle to rotate.
- Use the properties panel to edit position, opacity, and other values.
- Double-click a layer name to rename it.
- Use Duplicate and Delete to manage layers.

Hold **Alt** and drag a resize handle to crop the selected layer without moving its contents.

To reuse a widget in another layout, choose **Copy to layout…** or use **Ctrl+C**, switch layouts, and press **Ctrl+V**. You can keep the copy linked so the widget retains its state when switching scenes, or make it independent.

Use **Ctrl+Z** to undo and **Ctrl+Shift+Z** (or **Ctrl+Y**) to redo. Enable **Snap** to align layers with the canvas and other layers.
