**Deck** — страница `http://<IP компьютера>:<порт>/deck`: начальный экран с большими цветными плитками. Касание плитки переключает сцену OBS. Страница работает и в старых браузерах (поддерживается iPad с Safari 9), так что списанный планшет становится пультом для стрима.

![Страница Deck: группы плиток с горизонтальной прокруткой](/overlaycomposer/img/deck.png)
*Группы плиток прокручиваются по горизонтали. Белая рамка — текущая сцена; маленький квадрат в углу показывает состояние соединения.*

## Открыть на планшете

1. Разреши другие устройства: [Настройки → Network](../settings/), *All network interfaces*, перезапуск.
2. На планшете открой `http://<IP компьютера>:<порт>/pair?next=/deck` и введи код из Settings → Remote devices. После сопряжения откроется Deck.
3. Подключи obs-websocket ([Подключение к OBS](../obs-setup/)), иначе переключать нечего.

Раскладка — сетка из **4 рядов** квадратных клеток; высота экрана делится на четыре, поэтому вид одинаков в любой ориентации. У групп есть заголовки, они идут слева направо.

## Размеры плиток

| Размер (ш×в клеток) | Для чего |
|---|---|
| 1×1 | маленькая кнопка |
| 2×1 | широкая кнопка сцены (по умолчанию) |
| 3×1 | длинное название |
| 2×3 | крупная плитка |

## Редактор

Нажми **▦ Deck** в шапке редактора. Редактор превратится в редактор Deck (**← Overlay editor** возвращает обратно).

![Редактор Deck: группы и плитки слева, холст посередине, свойства плитки справа](/overlaycomposer/img/deck-editor.png)

- **Слева:** группы, **+ Group**, кнопки **+ 1×1 / + 2×1 / + 3×1 / + 2×3** добавляют плитку в текущую группу (первая ещё не использованная сцена) и список плиток группы.
- **В центре:** холст. Перетаскивай плитки, в том числе между группами. Плитка, которая не помещается, не сдвинется.
- **Справа:** выбранная плитка: название, сцена для переключения, **Ask for a second tap**, размер (неподходящие отключены), цвет, значок. Если плитка не выбрана, показывается группа: название, порядок, удаление.
- **Save deck** в шапке применяет раскладку; **Reset to default** делает по плитке на каждую сцену OBS.

Если раскладку тем временем изменили в другом месте, при сохранении предложат перечитать её. При закрытии с несохранёнными правками редактор спросит подтверждение. Если OBS не отдаёт список сцен, поле сцены становится текстовым: введи имя сцены точно как в OBS.

### Опасные сцены

Отметь **Ask for a second tap** у плитки (на скриншоте она подписана `confirm`): первое касание только «взводит» плитку, второе переключает сцену, так что случайное касание не оборвёт эфир.

## Безопасность

Deck, как и редактор, требует сопряжённого устройства. Касание отправляет только id плитки: действие всегда берётся из сохранённой раскладки, поэтому подделанный запрос не может потребовать произвольную сцену, а сцена должна существовать в OBS. Частота касаний ограничена.

Сама раскладка хранится в OverlayComposer; страница Deck и редактор читают одни и те же данные.
