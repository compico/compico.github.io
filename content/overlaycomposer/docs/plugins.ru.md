# Виджеты и плагины

Чтобы добавить виджет, используй **Add Source** в редакторе.

## Каталог плагинов

Выбери **Add Source → Plugin store…**, чтобы просмотреть каталоги плагинов. Каталог по умолчанию — [compico/oc-plugins](https://github.com/compico/oc-plugins). Также можно добавить собственные репозитории.

Плагины могут выполнять код внутри виджета. Устанавливай только те плагины и репозитории, которым доверяешь. Перед включением проверяй запрашиваемые плагином разрешения.

## Локальные HTML-виджеты

Выбери **Add Source → HTML file**, чтобы добавить HTML-файл или папку. Связанные CSS-, JavaScript-файлы и изображения можно хранить рядом.
