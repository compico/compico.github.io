# Widgets and plugins

Use **Add Source** in the editor to add a widget.

## Plugin store

Choose **Add Source → Plugin store…** to browse plugin repositories. The default catalog is [compico/oc-plugins](https://github.com/compico/oc-plugins). You can also add your own repositories.

Plugins can execute code inside the widget. Install only plugins and repositories you trust. Review the permissions requested by a plugin before enabling it.

## Local HTML widgets

Choose **Add Source → HTML file** to add an HTML file or a folder. Related CSS, JavaScript, and image files can live alongside it.

## Developing plugins

See the project's [PLUGINS.md](https://github.com/compico/overlaycomposer/blob/main/docs/PLUGINS.md) and [PLUGIN-REPO.md](https://github.com/compico/overlaycomposer/blob/main/docs/PLUGIN-REPO.md).
